# LoopDeck

LoopDeck 是基于 One Tool（2022）二次开发的一套开源云任务系统，支持网易云音乐、哔哩哔哩等平台的等级与日常任务。

项目已移除原作者失效的旧协议与加密文件，并对任务调度、平台协议、容器部署、日志和更新流程进行了持续重构。

## 当前版本

### v1.1.18（2026-08-02）

- 严格复刻 `api-enhanced` 当前 `scrobble` 协议，使用 `clientlog + EAPI + osx` 为每首歌分别提交单条 `startplay` 与 `play` 日志，并发即时上报；`time` 仅作为协议字段，不再等待歌曲实际播放。
- 每日300首只按网易云 `listenSongs` 的实际增量判定完成；接口返回成功但累计未新增时不再错误跳过，而是在约10分钟后换一批未提交的新歌复核补齐。
- 重试批次优先选取当年新歌与小众新歌歌单，保留真实歌单来源 ID，改善高听歌量账号大量命中旧歌的问题。
- 统一调度器与命令行调度器支持任务返回的补齐时间，并增加即时协议、异步入账和旧状态迁移回归测试。
- 每日补齐最多执行3批；第3批后仍未达到目标时停止当天补齐，避免对网易云接口重复施压。
- 网易云账号密码添加组件保留在页面上并标记为维护中：表单与登录按钮禁用、不再提交凭证，后端密码登录接口同步返回维护提示；正常添加账号请使用 APP 扫码登录及风控二次扫码验证。
