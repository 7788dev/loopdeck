# Agent Note: 通知发送持有执行锁并校验租约

Status: implemented

## Problem

通知原来只把 available_at 推后 120 秒。旧进程仍在发送但租约到期时，另一请求可以重复领取；旧进程随后按 ID 无条件写回，会覆盖新的发送结果或取消状态。

## Decision

通知仓库在领取前取得安装共享的 `notification:<id>` 锁，记录本次租约时间与尝试次数，完成写回同时比较状态、时间及次数。发送、取消、异常写回和析构均释放所属锁，不释放其他实例的锁。

## Alternatives considered

**仅增加租约秒数。** 无法给进程暂停、网络阻塞和时钟回拨设可靠上界。

**只给通知 Cron 入口加锁。** 无法保证其他调用者或迟到的结果写回仍属于当前发送者。

## Consequences

不增加数据库列。进程退出后文件锁释放，原时间租约继续提供恢复延迟；多节点部署仍需共享锁机制。`NotificationLeaseTest.php` 验证到期时不能重复领取、完成释放以及迟到结果不会覆盖新状态。
