# 更新日志

本文件记录 LoopDeck 的功能变更、修复与验证结果。最新发布以 GitHub Release 与 `VERSION` 为准。

## 当前版本

### v1.2.38（2026-10-25）

**后台公告置顶等级修复**

- 修复后台公告无法设置置顶等级的问题：字段白名单引入时遗漏 `sort`，列表置顶下拉提交后被过滤为空，接口直接失败；现已恢复并将取值钳制在 0-3。
- 「添加公告」弹窗新增置顶等级选择，新增公告可直接指定置顶，无需创建后再回列表设置。
- 69 个 PHP 离线回归与前端交互回归通过；已验证旧代码下新回归失败、新代码通过。无数据库结构变更；Compose 服务与环境变量不变。

### v1.2.37（2026-10-25）

**网易云任务登录失效检测修复**

- 依据生产实例真实上游形态修复 cookie 过期识别：等级接口对失效会话返回匿名模板（`userId` 为 0），账号接口返回 200 且 `account` 为空，其余 VIP 接口返回 301。
- `vip_growth_task` 检测到上述形态时立即标记账号失效并提示「登录已失效，请重新扫码登录」，不再每日重复无意义的「乐签打卡失败」等泛化失败；子步骤读到 301/401 同样触发。
- `login_work` 修复对「200 + 空 account」误报「登录成功」的问题；传输失败仅报告「登录状态检查失败」，不误判健康账号失效。
- `yunbei_task`、`evaluate`、`musician_task` 的 301/401 同样映射到账号失效流程，网易云白名单任务失效检测全覆盖。
- 69 个 PHP 离线回归与前端交互回归通过；另在生产镜像一次性容器内以真实失效账号重放验证。无数据库结构变更；Compose 服务与环境变量不变。

### v1.2.36（2026-10-23）

**模板输出安全加固、交互细节与 PHP 基础镜像 CVE 修复**

- 模板输出默认使用 `html_escape`，编译缓存按过滤策略隔离；账号昵称、通知标题、后台配置与上游消息统一转义。
- 账号列表/详情页改用以 `data-*` 属性驱动的交互，移除动态内联事件与脚本字符串拼接；扫码页补充键盘操作、加载与失败反馈。
- 登录按钮新增提交中状态与错误抖动提示；危险操作确认文案明确任务停止与状态清理；新增对减少动态效果偏好的适配。
- Docker 基础镜像由 `serversideup/php` v4.5.1（PHP 8.2.32）升级至 v4.5.3（PHP 8.2.35），修复 CVE-2026-109618/109619 未认证远程代码执行漏洞；镜像 digest 经 Registry 实测核验。
- 新增脱敏示例截图、README 版式重构、MIT 许可证与使用免责声明。
- 68 个 PHP 离线回归与前端交互回归通过。无数据库结构变更；Compose 服务与环境变量不变，基础镜像内 PHP 由 8.2.32 升至 8.2.35。

### v1.2.35（2026-10-13）

**并发状态一致性、账号生命周期与旧库升级修复**

- 会员到期处理在用户锁内重新检查有效期，避免覆盖刚完成的续期；统一网易云、哔哩哔哩 Cron 与 CLI 的账号和任务状态边界。
- 任务配置仅在空闲时保存，领取后重新读取最新配置；保留哔哩哔哩核验标记、重试次数及 Epic 提醒进度，防止旧执行结果覆盖新设置。
- 同一平台账号的并发绑定按账号互斥；删除账号、任务和日志使用同一事务，网易云状态文件在提交成功后清理。通知发送也持有执行锁并校验所属租约。
- 修复长邮箱和 IPv6 无法写入验证码记录的问题；旧兑换码表自动转为 InnoDB，保证兑换失败可以回滚，并修正旧公告表的升级 SQL。独立迁移不会再被无关索引冲突全部阻断。
- 支持通过可选的可信代理配置记录真实客户端 IP；普通页面与 AJAX 异常分别使用 HTML 和 JSON 响应。离线结构测试固定使用内存数据库，避免触碰安装配置中的真实数据库。
- 完整问题、修复及验收证据见[系统分析与修复报告](SYSTEM-ANALYSIS-2026-10-13.md)。
- 68 个 PHP 离线回归与前端交互回归通过，服务器 21 项 HTTP 断言、真实 MySQL 集成及备份恢复验证通过。数据库变更为验证码邮箱/IP 列扩容及旧兑换码、公告表引擎迁移；Compose 服务不变，新增可选环境变量 `TRUSTED_PROXIES`。
