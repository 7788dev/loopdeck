# Agent Note: 二维码生成评估全部掩码

Status: implemented

## Problem

发布离线回归时，原生成器只随机抽取两个掩码。相同 URL 在不同随机种子下生成不同二维码，种子 0、2、5、25 能复现项目内识别器无法解码的情况。

## Decision

[生成器](../../../../extend/netease/Qrcode.php)评估全部八个掩码并选择惩罚分最低者，相同参数输出不再依赖随机状态。[回归](../../../../tests/QrcodePayloadTest.php)覆盖四个曾失败的种子，检查完整 URL 和微信协议载荷。

## Alternatives considered

**失败时反复重跑测试。** 掩盖真实扫码失败并使构建不稳定。

**只扩大二维码留白。** 将留白从 2 改为 4 的对照实验仍复现相同失败，因此保留现有尺寸。

## Consequences

每次生成由评估两个掩码增加至八个，换取输出稳定和完整的质量评估；不涉及账号、支付逻辑或数据库。该改动不意味着项目识别器可以识别所有外部二维码。
