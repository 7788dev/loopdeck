# 性能优化与四平台接入验收

本次目标：修复已确认的性能问题，完整接入百度贴吧、夸克网盘、天翼云盘与阿里云盘。沿用单站点、账号配额、任务白名单、账号隔离及统一日志和通知规则。

前端约束：复用现有布局、侧栏、账号卡片、详情任务表和日志面板，仅对必要字段和操作进行最小调整。阿里云盘范围已确认：签到、领奖与账号/容量概览，不包含转存或文件同步。

## 性能范围

- [ ] 网易云、哔哩哔哩详情页使用账号快照，第三方请求通过独立刷新操作执行，缓存按账号及凭据版本隔离。
- [ ] 调度 worker 独立循环，慢分片不阻塞其他分片；任务执行与网页 PHP-FPM 资源隔离。
- [ ] 网易云短暂入账等待、合伙人评分间隔使用可恢复的延迟状态，保持真实结果核验和同账号顺序执行。
- [ ] 任务补齐及调度元数据使用批量查询，限制每轮候选读取量，复用安全的 HTTP 连接资源。
- [ ] 首页统计短缓存、账号列表分页、日志数量缓存与写入/删除失效；保留日志编号语义。
- [ ] 提供旧数据库索引检查和安全补齐，维护清理限时分批；保留任务和账号数据。
- [ ] 用离线行为回归、查询次数/受控耗时基准验证上述变化。
