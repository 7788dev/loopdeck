# 内部来源与复用

用户于 2026-10-03 将 LoopDeck 当前认可的界面命名为 **GOD 风格**。这是对该项目布局、比例、色彩与交互习惯的提炼，不是新前端框架，也不替换任何上游许可。

视觉基准来自 LoopDeck v1.2.21 的优化结果及 v1.2.22 的单模板整理。原始参考是 RuoYi 经典版 v4.8.3（提交 7995a83e04e1a88aaea5a8a7c50570dffcb145e0）和 RuoYi-Vue3 v3.9.2（提交 838965c5a18d2c61b73ec30c6e288057aaa08b63）。认可的结果包含项目原有信息组织方式，并非完整照搬上游页面。

技能内 `assets/god.css` 和三个 HTML 骨架为独立、无框架的提炼实现，不包含 Bootstrap、jQuery 或原项目 PHP 模板。可以把设计变量映射到目标项目现有组件，避免迁移时依赖 LoopDeck 的绝对路径、接口或目录。截图来自隔离测试数据，仅用于内部视觉参考，不作为新产品的内容资源或真实业务数据。
