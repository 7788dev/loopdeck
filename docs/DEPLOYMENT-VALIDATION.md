## 旧版升级的数据核对

先使用 1.2.3 创建测试管理员、账号和数据标记，再保留旧 Compose、旧数据库凭据及持久化卷，仅重建 `app`、`scheduler`、`updater` 为 1.2.4。升级前后逐项比较：

- `config/Db.php` 文件及实际数据库名称的 SHA-256；
- 管理员、账号、任务定义、任务日志和测试标记的记录指纹；
- 管理员密码校验结果及管理员权限；
- MySQL 容器 ID、安装入口锁定状态和网站响应。

所有检查一致。旧 Compose 没有新增 `MYSQL_HOST`，升级后仍能正常读取原数据库。
