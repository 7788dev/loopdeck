1. 开始使用
这里可以做什么？

{:html_escape(config('web.webname'))} 可以集中管理平台账号、设置每日任务，并查看执行进度和结果。

  • 网易云音乐：每日签到、VIP 成长、每日 300 首，以及音乐人和合伙人任务。
  • 哔哩哔哩：每日观看、投币、等级经验和大会员积分等任务。
  • AnyRouter：绑定账号，通过代理完成每日签到。
  • AgentRouter：绑定用户名和密码，每天重新登录签到、查询余额并退出。
  • Epic 商城：查看每周免费游戏，按个人设置接收提醒。
  • 收款码合一：合并支付宝、微信和 QQ 收款码。

可用功能以本站开放的菜单、账号资格和任务列表为准。

第一次使用，怎样添加账号？

先在兑换码兑换页面确认会员状态和可用账号总数，再进入对应平台的「添加账号」。

  • 网易云音乐：使用网易云音乐 APP 扫码，在手机上确认后点击「扫码完成，点击验证」。账号密码登录仍在维护中；若出现安全验证，请按页面提示完成。
  • 哔哩哔哩：支持 APP 扫码和手机号短信登录。扫码后需在手机上确认，再点击验证；短信登录需按提示完成验证并输入短信验证码。
  • AnyRouter：填写 Cookie、API User，并选择代理方式，点击「验证并添加」。具体获取方式见下方 AnyRouter 说明。
  • AgentRouter：填写用户名、密码和备注，选择「平台代理 / 自有代理」，点击「验证并添加」。验证会登录并退出一次，可能完成当天签到。

绑定完成后进入「管理账号」，设置挂机时间，并开启需要执行的任务。二维码过期时请重新获取。

账号失效或不再使用时，如何处理？

账号显示登录失效时，网易云和哔哩哔哩可在添加账号页重新登录同一个平台账号；AnyRouter 请在「更新账号」中更新 Cookie；AgentRouter 请核对用户名，并更新已变更的密码。更新后检查任务开关与挂机时间。

更新自己已绑定的账号不会重复占用名额。同一个平台账号不能同时绑定到本站的不同用户；提示已存在时，请联系管理员核实归属。

删除不再使用的账号可释放名额，同时会移除对应任务和运行日志，请确认后再操作。

账号总数、本站 VIP 和兑换码是什么关系？

所有平台共用一个账号总数上限。例如总数为 7 个，可以绑定 2 个哔哩哔哩和 5 个网易云账号，也可以按自己的需要分配；新增收款码记录也会占用名额。

会员权限和账号额度来自注册赠送、管理员设置或管理员提供的兑换码。一张兑换码可同时开通或延长会员，并设置账号总数；兑换后的实际权益可在兑换码兑换页面查看。

本站 VIP 用于使用本站的 VIP 功能。网易云黑胶 VIP、音乐人或合伙人资格、哔哩哔哩大会员等，仍需对应平台账号自行具备。

2. 平台任务与工具
网易云每日 300 首怎样配置，为什么还在核验？

在账号详情开启「每日 300 首」，通过任务旁的设置按钮选择歌曲来源。每日目标可设置为 1～300 首，留空按 300 首执行；自定义歌单可填多个歌单 ID，用英文逗号分隔，留空则由系统选择歌曲。

任务以网易云实际增加的累计听歌数判断完成。上报后可能需要等待结算，账号详情会显示已确认进度和本轮截止时间，系统会自动补齐与核验。

从首次执行起，本轮最多持续 30 分钟，且不跨自然日。补挂不会重置当天基线或延长本轮时间；达到目标或到期后记录最终结果，运行日志和对应推送只展示最终成功或失败。

正在核验时请等待页面给出的结果。未达目标时，可查看最终日志中的实际首数和失败原因。

网易云音乐人和合伙人任务如何配置？

这两类任务需要平台账号具备相应资格，请先确认在网易云官方工作台可以使用。

  • 音乐人歌曲 ID：填写自己的歌曲 ID；留空时系统会尝试查找自己的专辑歌曲。歌曲分享链接中的 song?id=123456，数字部分就是歌曲 ID。
  • 粉丝 ID：回复粉丝私信需要填写对方的用户 ID，可从用户主页分享链接中的 id 或 userid 参数获取。不要把音乐人页面的艺人 ID 当成用户 ID。
  • 私信内容：可以自行填写，留空使用系统默认祝福语。
  • 合伙人评分：在任务设置中填写评分星数，例如 3,4 表示在 3～4 星间选择；允许 1～5 星，默认 2～3 星。

任务会检查子任务执行情况与奖励领取结果，部分失败会在日志中说明；没有可领取奖励属于正常情况。

网易云听歌任务工具如何使用？

本站开放该工具时，可从网易云菜单进入「听歌任务工具」，选择已登录的账号，填写歌曲 ID 和播放次数后提交。

歌曲 ID 取歌曲分享链接中的数字，例如 song?id=123456 对应 123456。播放次数必须为 1～300 的整数，单次最多 300 次；若页面显示每日提交次数限制，还需遵守该限制。

工具提交的是播放记录，重复播放同一首歌不代表会增加同等数量的累计听歌首数，最终统计以网易云官方数据为准。

哔哩哔哩投币和等级经验怎么看？

在「每日投币」旁的设置按钮中选择「随机热门」或「关注列表」，投币数量可设为 1～5。投币会消耗账号里的真实硬币，请按自己的需要设置。

已达到投币上限的视频会被跳过，再尝试其他候选。硬币不足、候选视频不足或平台拒绝时，请查看运行日志中的具体原因。

账号详情的「今日等级经验」分别展示登录、观看、投币和大会员加成，只合计已确认的经验。到账延迟时会自动复查，默认每 5 分钟一次，当天两小时内最多复查 24 次。

哔哩哔哩大会员积分和等级经验有什么区别？

大会员积分用于兑换平台权益，不计入等级经验。「大会员积分任务」有独立的任务开关，需要账号具备在期的哔哩哔哩大会员资格。

任务包括积分签到，以及任务中心已开放的福利积分、浏览权益页和浏览装扮商城奖励。部分福利每人限领一次，已完成项目不会每天重复领取；手机专属或消费类任务请按平台提示自行完成。

结果尚未确认时会继续查询到账状态。遇到明确的风险验证，请先到哔哩哔哩完成验证，再检查任务状态。

AnyRouter 的 Cookie、API User 和代理怎样填写？
  1. 在浏览器登录 AnyRouter，打开开发者工具的「网络」面板并刷新控制台页面，找到 /api/user/self 等账号接口请求。
  2. 从请求头复制包含 session 的 Cookie，以及 new-api-user 的数字值，分别填入「Cookie」和「API User」。可以填写备注名以便区分账号。
  3. 选择「平台代理」使用站长配置的出口：由站长选择内置代理池、站长订阅链接或常规代理。也可选择「提供代理」填写自己服务器可访问的公网 HTTP / SOCKS5 地址，支持用户名密码认证。
  4. 点击「验证并添加」，再进入账号详情设置挂机时间并开启「每日签到」。保存账号只验证登录，签到按任务计划执行。

凭据失效时从「更新账号」更换 Cookie；更新表单中 Cookie 或已配置的代理留空，会保留原值。平台代理来源由站长在「系统设置 → 功能插件设置 → AnyRouter 平台代理」维护，普通用户无需填写站长订阅。平台代理不可用时可联系管理员检查，或改用自己的代理。

「刷新信息」用于查询账号状态；需要补挂时使用「申请补挂」，并在运行日志中查看签到结果。实际领取间隔由 AnyRouter 决定。

AgentRouter 怎样绑定、配置代理并自动签到？
  1. 已有 AG 账号可直接填写用户名和密码；尚未注册可前往 注册 AgentRouter。备注可用于区分多个账号。
  2. 选择「平台代理」使用站长配置的订阅或常规代理，或选择「自有代理」填写自己的公网 HTTP / SOCKS5 地址。平台代理仅由站长在「系统设置 → 功能插件设置 → AgentRouter 平台代理」中配置。
  3. 点击「验证并添加」，验证会登录并退出一次。进入账号详情设置每日签到时间，并开启「每日签到」；首次保存通常从次日开始，当天需要执行可「申请补挂」。

AG 的登录动作本身就是签到。每天使用新会话登录一次，查询余额后退出登录，下次再重新登录。打开账号详情或更新页只显示已存的信息；最近一次成功签到后会更新余额，未读到的金额显示暂不可用。

平台代理优先复用最多 3 个曾完成签到的节点，首次不可用保留，连续两个执行日不可用后移除，再尝试后面的节点或重新筛选订阅。不会每天强制随机换节点，站长更换来源后重新筛选。

更新表单中密码和已配置的代理留空会保留原值。用户名或密码错误时请更新凭据；网络、网站验证或退出未确认会自动重试，达到上限后暂停任务，处理原因后再开启。

Epic 免费游戏如何查看和接收提醒？

在Epic 商城查看当前和即将开始的免费活动，点击游戏卡片进入商店。领取游戏需在 Epic 商店自行完成。

提醒在个人中心 → 信息推送中设置：开启推送总开关和接收渠道，勾选「Epic 每周免费游戏提醒」，再设置每周五发送时间并保存。该提醒需要本站会员权限。

可使用 Bark、PushPlus、WxPusher，以及本站已开放的邮件渠道。

收款码合一支持什么图片？

在生成收款码页面填写收款信息，上传需要合并的支付宝、微信或 QQ 收款二维码，生成后下载保存。

支持 PNG、JPEG 和 WebP，每张不超过 2 MB，宽高分别不超过 4096 像素。超出限制时请裁剪或缩小图片后再上传；识别失败时确认二维码完整、清晰且未被遮挡。

3. 运行与常见问题
任务没有运行或没有完成，应该怎样处理？
  1. 确认平台账号登录正常，并具备任务需要的平台资格；VIP 任务还需本站会员有效。
  2. 进入账号详情，确认已设置挂机时间、目标任务开关已开启，再查看任务进度、下次执行时间和运行日志。
  3. 显示「重试中」或正在核验时，等待自动处理；账号失效时先更新登录，任务已暂停时先处理日志中的原因，再重新开启。
  4. 需要重新排队时点击「申请补挂」。补挂受冷却时间限制，正在执行的任务不会重复启动，也不会延长听歌核验期限。

ANY 和 AG 已接入统一调度，按北京时间每天执行。首次保存计划通常从次日开始，并可能有短暂的随机延迟；无需一直打开网页。当天需要运行可「申请补挂」。普通用户无需设置监控地址，站长可在「任务监控列表」确认统一调度入口与部署调度器。

仍未解决时，请向管理员提供平台、任务名称、发生时间和日志中的错误说明。反馈截图请遮住 Cookie、密码及推送凭据。

联系管理员

如何开启任务推送，收不到消息时检查什么？

进入个人中心 → 信息推送，开启总开关，选择接收渠道并填写凭据，再勾选需要接收的提醒。先保存设置，再测试对应渠道。

  • 接收渠道：Bark 填设备 Key；PushPlus 填用户 Token；WxPusher 填 AppToken 和已订阅用户的 UID。邮件渠道仅在本站配置可用时显示。
  • 提醒内容：可分别开启单项成功、最终失败、账号失效、会员到期及每日任务总览。重试中的任务不会重复发送最终失败提醒。
  • 每日总览：按北京时间发送，默认 22:00，汇总发送前当天已执行任务的结果；有夜间任务时请把总览时间设在任务之后。

收不到消息时，依次检查总开关、渠道开关、提醒内容和凭据，再查看「最近投递记录」的状态及错误原因。「渠道已受理」表示推送服务已接收，手机或邮箱是否展示还取决于接收端设置。

忘记密码或想修改密码怎么办？

忘记密码：在登录页点击「找回密码」，填写账号当前绑定的邮箱和验证码。注册时默认邮箱是 QQ 邮箱；如果在个人中心改过邮箱，请使用修改后的地址。收到邮件后按链接重置密码，链接过期或已使用时需重新申请。

修改密码：进入个人中心，填写当前密码、新密码和确认新密码。修改成功后使用新密码重新登录，之前的找回密码链接会失效。
