# Agent Note: 网易云扫码验证的页面生命周期

Status: implemented

## Problem

PJAX 刷新会再次执行页面脚本。旧页面尚未触发的首轮定时器引用全局轮询句柄，随后可能清掉新页面的验证轮询；固定间隔还会让慢请求重叠。

## Decision

每次页面挂载持有独立闭包；重挂载和 `pjax:beforeReplace` 都清理旧轮询、请求和成功跳转。每轮验证独立持有 timeout、XHR 与停止状态，仅在本次响应结束后安排下一轮请求。

获取新二维码会终止此前验证并使旧登录请求失效。登录回调按请求对象身份确认所属尝试，防止旧请求阻止新扫码或覆盖新页面。上游提示始终作为纯文本写入。

## Alternatives considered

**只清掉全局 interval。** 未执行的首轮 timeout 仍会进入旧闭包，可能操作新句柄。

**只检测页面中是否存在二维码节点。** 新页面存在同名节点，不能证明请求属于当前挂载。

**只用一个登录中布尔值。** 更换二维码后旧请求仍未完成时会阻塞新的登录，旧回调也不能区分自身是否过期。

## Consequences

`QrUploadAndVerificationTest.js` 通过公开扫码交互覆盖快速重挂载、换码、离页、慢请求、过期回调、延迟跳转和上游提示转义，并纳入前端聚合套件。
