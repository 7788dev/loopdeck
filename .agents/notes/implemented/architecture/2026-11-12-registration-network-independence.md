# Agent Note: 正常注册不依赖共享或最后登录 IP

Status: implemented

## Problem

注册 IP 开关读取用户表的 `login_ip`，而每次成功登录都会覆盖该字段。实测中，IP A 注册后换到 IP B 登录，A 的第二次注册由失败变为成功，B 的首次注册反而被拒绝。即使改成保存固定注册 IP，同一家庭、校园、公司或运营商出口下的不同用户仍会被误拦。用户明确要求修复以正常注册不受拦截为优先目标。

## Decision

- [注册模型](../../../../app/index/model/Users.php)不使用 IP 决定是否接受注册；旧数据库的 `reg_iplimit` 值也不再影响注册。注册和登录继续记录当前真实 IP。
- [后台注册设置](../../../../app/admin/view/system/set/reg.html)移除 IP 限制开关，说明共享网络用户可分别注册。[后台保存接口](../../../../app/admin/controller/Ajax.php)拒绝旧开关写入并提示刷新页面；新安装不再种入该配置，旧数据无需迁移。
- 保留验证码、用户名与 QQ 去重、站点关闭注册、注册权益赠送。登录失败计数仍独立执行，不进入注册判断。
- [注册网络回归](../../../../tests/RegistrationNetworkTest.php)覆盖旧配置两种值及缺省值、共享 IPv4/IPv6、可信代理、换网络登录、重复提交、已有登录失败计数及保留的输入校验。[功能移除回归](../../../../tests/FeatureRemovalTest.php)钉住旧设置不可写、界面与安装种子不恢复限制。

## Alternatives considered

**新增固定注册 IP 字段，继续每 IP 只允许一个账号。** 解决登录覆盖但仍把共享网络的不同用户视为同一个人，不满足正常注册优先的要求；旧安装也无法还原已经被覆盖的历史注册 IP。

**把永久限制改为每 IP 注册频率或每日名额。** 忙碌的公共出口仍可能让正常用户耗尽名额，时间阈值不能可靠区分滥用与正常注册。

**仅把开关默认值改为关闭。** 已开启限制的旧部署仍会误拦，后台也继续提供误导性控制。

## Consequences

不同用户可以在相同网络分别注册，登录位置变化不改变注册结果；注册成功后重复提交仍按用户名去重。IP 不再承担重复注册识别，注册保护依赖验证码与账号标识去重，不能把共享地址当作用户身份。无需数据库结构变更，也不自动删除旧配置记录。
