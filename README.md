# LoopDeck

LoopDeck 是基于 One Tool（2022）二次开发的一套开源云任务系统，支持网易云音乐、哔哩哔哩等平台的等级与日常任务。

项目已移除原作者失效的旧协议与加密文件，并对任务调度、平台协议、容器部署、日志和更新流程进行了持续重构。

## 当前版本

### v1.1.22（2026-08-12）

**网易云每日300首：修复跑不满的问题**

- 上报协议与上游 `api-enhanced` 的 `scrobble` 模块保持一致，本次未作改动；问题出在其上的每日额度编排层。
- 每日额度不再按“已提交的上报事件数”扣减，改为按 `listenSongs` 的实测增量计算剩余量。此前只要发满 300 条事件，当天缺口就再也补不回来，后续运行全部落入“只复核不上报”分支。
- 候选歌曲改为纯歌单来源，每首歌携带真实的 `sourceId`（歌单 ID），替换掉搜索来源写死的 `sourceId=0`。
- 永久 30000 条上报历史黑名单降级为“仅当天去重”，仅保留为排序提示，避免候选池随天数枯竭。
- 歌曲时长下限由 120 秒下调至 60 秒，候选不足时自动放宽；修复 `netease` 命名空间下永远不会匹配的 `catch (Throwable)`。
- 任务日志新增每轮真实增量、起播/听歌接受数、被拒错误码与复用歌曲占比，便于判断计数规则。
- 任务配置弹窗新增“自定义歌单 ID”和“每日目标首数”，后端配置项改为白名单校验。

**安全加固**

- 修复易支付回调可被重放提权：回调改为与订单绑定，校验商品类型与金额，受益人取订单归属而非当前会话，并以条件更新做一次性认领。分站域名改由订单读取，回调地址不再使用 `Host` 头拼接。
- 修复后台用户与分站管理缺少分站隔离：读写限定在管理员所属站点，保护主站超管，后台详情不再返回密码哈希。
- 修复找回密码链接使用 `Host` 头拼接；令牌改为 CSPRNG 生成、30 分钟过期、常量时间比较并在使用后失效。
- 修复余额、配额、会员与卡密兑换的非原子扣减导致的并发双花。
- 网易云调度不再把账号 Cookie 与 `RUN_KEY` 放入 URL 自调用，改为进程内执行并限制任务名白名单。
- 修复公告存储型 XSS、收款码 DOM XSS 与开放重定向；会话 Cookie 增加 `HttpOnly` / `SameSite` / 自适应 `Secure`；登录增加频率限制并统一错误提示、登录后轮换会话 ID；恢复调度器 TLS 校验。

**性能**

- 候选采集由最坏约 270 次串行请求降至 2 到 3 次，歌单曲目每轮只拉取一次。
- `playlist_detail` 单次拉取上限由 100000 收敛至 600 首。
- 调度器 `CURLOPT_TIMEOUT` 由 1 秒（短于连接超时）调整为合理值，避免长任务被中途掐断。
- 新增 `runtime/netease-daka/` 状态文件清理：删除账号时一并移除，调度器按 `DAKA_STATE_RETENTION_DAYS`（默认 30 天）清理孤儿文件。
