# LoopDeck

LoopDeck 是基于 One Tool（2022）二次开发的一套开源云任务系统，支持网易云音乐、哔哩哔哩等平台的等级与日常任务。

项目已移除原作者失效的旧协议与加密文件，并对任务调度、平台协议、容器部署、日志和更新流程进行了持续重构。

## 当前版本

### v1.1.13（2026-08-02）

- 修复网易云“每日300首”误用 NCBL 文件上传确认的问题，恢复使用能进入官方听歌记录的计数协议。
- 执行前合并本地历史与网易云官方已听歌曲记录，减少重复歌曲，提升新号完成300首的成功率。
- 任务响应精简为“上次累计听歌、本次累计听歌、已打卡首数”。
- 保留 NCBL 协议供单曲播放工具使用，并补充网易云工作流回归测试。
