系统任务配置

开启本地回路能使监控运行更迅速。本地回路主要用于解决开启CDN之后访问IP和源站IP不一样而导致无法监控或监控慢的问题。

监控请求的鉴权密钥。容器部署时由环境变量 CRON_KEY 自动生成并写入，修改后两个密钥均可通过验证（便于轮换）。请求请通过 X-Cron-Key 请求头携带密钥，请勿将密钥拼入 URL

每次运行任务数是指在单个系统内，每运行一次监控文件所能够执行的任务数，建议50

用户申请补挂间隔的冷却时间，建议300
