# Agent Note: 撤回 GLaDOS／Railgun 与配套资源框架

Status: rejected（2026-11-15，真实 CF 验证未通过，用户取消接入）

## Problem

GLaDOS／Railgun 接入需要通过 CF 验证。隔离服务器的真实浏览器对照仍返回 `600010`，没有取得可用票据，无法证明自动签到可以工作。用户因此要求删除本次平台功能改动。

## Decision

撤回平台控制器、账号页面、客户端、签到与兑换执行器、代理池、任务注册、安装种子、导航和通知名称，以及随接入新增的浏览器容器、公平队列、资源槽、平台注册表和相关配置、文档与专用测试。原有调度锁、租约和其他平台恢复接入前的实现；[移除回归](../../../../tests/FeatureRemovalTest.php)检查公共动作不存在、任务不受调度支持、目录与部署配置不存在，并通过实际任务列表查询确认不再自动补建该平台。

帮助中心、网易云提示、额度说明及独立发现的 [Validate 导入大小写修正](../../../../app/index/validate/Users.php)保留。原有两份 implemented 接入记录合并到此否决记录，避免继续描述已撤回的实现。

## Alternatives considered

**继续尝试浏览器验证。** 当前真实验证没有成功依据，继续投入与用户取消接入的要求冲突。

**单独保留本次资源框架。** 它随取消的平台新增，当前没有其他已验收接入需要它；保留会扩大这次未落地功能的维护范围。

## Consequences

本次平台没有提交、发版或部署到生产，生产数据库无需迁移。服务器测试容器、测试镜像、独立目录及本轮独占构建缓存已清理，清理核验时生产健康检查返回 HTTP 200。此记录只保留取消原因，不保存凭据或可用接入说明。

## Verification

同一移除回归从删除前的 `Cancelled GLaDOS controller actions remain auto-routable` 转为 `Feature removal and retained entitlement view tests passed`，随后完整离线套件 83 项 PHP 回归与 Node 前端交互测试全部通过。第二轮核对确认 25 个定向恢复文件与 HEAD 内容一致，帮助中心仅移除该平台的两个列表项、账号更新措辞和独立问答；其他保留文件的哈希不变。全范围检索确认应用、部署配置和公开文档无平台或配套框架残留，旧 implemented 记录没有失效入链。
