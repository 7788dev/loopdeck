# 若依前端资源

来源：[RuoYi 经典版](https://github.com/yangzongzhuan/RuoYi)，MIT 许可见 [LICENSE](LICENSE)。

本目录选用经典版的 Bootstrap 3.4.1、jQuery、Font Awesome、基础样式、皮肤和登录素材。LoopDeck 使用自己的 ThinkPHP 控制器、权限、业务数据、表单和任务接口；不包含若依的 Java 服务、演示菜单、示例页面或示例业务数据。

视觉调整另参考 [RuoYi-Vue3 v3.9.2 的官方主分支](https://github.com/yangzongzhuan/RuoYi-Vue3/tree/838965c5a18d2c61b73ec30c6e288057aaa08b63)：白色顶栏、深色侧栏、文字层级和组件间距。`img/login-background-vue3.jpg` 来自该提交的登录背景，许可见 [LICENSE-Vue3](LICENSE-Vue3)。这是视觉适配，没有引入 Vue 或替换现有业务接口。

`css/ruoyi-loopdeck.css` 适配单页 PJAX 导航、响应式布局及现有业务表单。表格使用项目现有的 DataTables 核心和 Bootstrap 3 适配器。没有引入若依未使用的表格、树、代码生成器和演示组件脚本。
