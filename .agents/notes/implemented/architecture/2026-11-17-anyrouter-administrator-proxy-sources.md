# Agent Note: AnyRouter 站长平台代理来源

Status: implemented

## Problem

ANY 的 HTTP / SOCKS5 列表地址固定在代码中，站长无法更新失效的镜像，也不能在后台选择自己的订阅或常规代理。旧部署的环境固定出口又会覆盖池选择。普通用户需要沿用「平台代理 / 提供代理」，不能看到站长的订阅、节点认证或内部地址。

## Decision

- [AnyRouterProxySettings](../../../../app/service/AnyRouterProxySettings.php)将选定类型、列表与私人来源保存为 `configs` 中的 `anyrouter_private.proxy`，不新增表。默认保持内置 HTTP / SOCKS5 列表及三个镜像；每种协议最多 8 个列表 URL，可编辑、恢复并去重。订阅和常规代理只回显配置状态，留空保留同类型秘密，切换类型要求新来源，清除时改用内置池。
- [后台](../../../../app/admin/view/system/set/plugin.html)通过独立管理员保存入口校验。共享配置加载和通用配置写入均排除私有前缀，包括大小写变体与旧缓存。防火墙只对有效后台设置操作的标量 `source` 保持凭据不透明；其他字段、嵌套值与其他路由继续检查。
- [代理池](../../../../app/service/AnyRouterProxyPool.php)只使用选定来源，不在订阅或固定代理失败后回退到公开池。列表下载显式直连、固定解析后的公网 IP、保留 TLS/SNI，禁止重定向并限制字节和时间。订阅复用已有 AG 节点解析与受限 Mihomo relay，只向引擎传单个规范化节点。
- 公共候选与最多 3 个匿名可用的订阅节点保存在 `0600` 运行时缓存，缓存携带活动来源指纹，更换来源不会复用旧节点或游标。订阅记录与 AG 的已完成签到记录不同：ANY 缓存只证明匿名预检，不宣称奖励已领取。失败扫描保留游标，限制节点数与总时长。
- 选择与保存共用安装级平台代理锁。[客户端](../../../../extend/anyrouter/Client.php)持有 relay 与锁直到[执行器](../../../../app/service/AnyRouterTaskExecutor.php)完成账号读取或单次签到，在 `finally` 关闭；未使用客户端和异常路径也能清理。匿名探测、WAF Cookie、身份读取与签到保持同一出口，沿用[原协议约束](2026-11-12-anyrouter-proxy-checkin.md)。
- 为旧部署保留一次兼容：后台尚未保存 ANY 设置时，非空 `ANYROUTER_PLATFORM_PROXY` 显示为常规代理；首次后台保存后以数据库选择为准，不存在隐含环境覆盖。
- [任务监控](../../../../app/admin/view/system/set/cron.html)展示真实统一任务和通知入口，说明 ANY / AG 由 `/cron/task` 调度，不编造单独的平台路由。[帮助中心](../../../../app/index/view/console/user/faq.html)说明同日补挂、AG 登录即签到及平台来源由站长维护；AG 首次日期规则见[首次计划决策](2026-11-17-agentrouter-first-day-schedule.md)。

## Alternatives considered

**在普通用户个人中心配置站长来源。** 与用户要求的权限归属不符，也会把站长订阅变成个人设置；账号只选择平台代理或自有代理。

**后台填写后仍优先读环境出口。** 选择结果与实际出口不一致。旧环境仅在首次保存前按常规代理兼容，已保存的站长选择优先。

**直接把完整订阅交给代理引擎。** 会接受远程规则、提供器、监听器和路径；复用受限节点转换与有认证的回环 relay。

**为 ANY 重写 AG 的连接机制或新增常驻代理服务。** 本轮只复用已验收的解析和转发组件，避免改变 AG 完成签到后记录节点的语义，也不新增服务或开放端口。

**在监控页为两个平台拼接独立 cron 地址。** 仓库没有这两个独立入口，真实执行由统一调度完成；展示其覆盖范围和实际地址。

## Consequences

没有数据库结构、Compose 服务或环境变量名称变化。ANY 订阅需要已有镜像中的 Mihomo 组件，公共列表仍不保证持续可用。私有来源和节点留在本站，缓存与 relay 文件不进入 Git；新行为由管理员保存、实际 jQuery HTTP 请求、三种出口与清理回归覆盖。

97 个 PHP 离线回归及前端套件通过；独立 Edge 浏览器执行五次真实保存，验证三种来源、清除、恢复、重复挂载、手机布局、监控地址、帮助折叠与普通用户权限。原支付移除检测限定站内钱包和支付入口，保留平台帮助中的上游余额说明；钱包导航仍禁止。
