# Agent Note: 删除在线支付，仅保留管理员分配权益

Status: implemented

## Problem

LoopDeck 用于免费技术交流，用户要求直接清除原有易支付及在线购买逻辑，配额通过注册赠送、管理员设置或管理员生成兑换码发放。

## Decision

支付控制器、SDK、下单与结算模型、余额扣费、支付配置和订单管理、定价页面及购买入口均删除。注册不再赠送余额，后台不再编辑余额。首次安装不创建支付表、余额字段和价格配置；已有数据库记录不自动删除。

[兑换页](../../../../app/index/view/console/shop/card.html)始终可访问，不依赖旧下单方式配置。配额不足时引导联系管理员或兑换。现有会员权限、注册赠送和会员兑换码仍可用于管理员分配任务权限。

## Alternatives considered

**通过开关停用支付。** 仍保留可被重新打开的支付逻辑，与用户明确要求不符。

**只删除导航。** 旧下单与回调地址仍可触达，不能完成移除。

**同时删除所有会员权限及历史数据。** 用户要求是取消在线支付，未要求改变任务权限体系或抹除历史记录。

## Consequences

旧支付链接和回调不再有控制器可执行，旧订单不会自动入账。已有配额与会员时间保留。移除边界由 [FeatureRemovalTest](../../../../tests/FeatureRemovalTest.php)固定，保留流程由 [QuotaWorkflowTest](../../../../tests/QuotaWorkflowTest.php)验证。
