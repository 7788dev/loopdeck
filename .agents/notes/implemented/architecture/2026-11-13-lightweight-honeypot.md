# Agent Note: 入口前蜜罐与限量样本统计

Status: implemented

## Problem

用户要求攻击看起来成功、取得无用数据后看到尾部调侃，同时不影响正常使用并控制内存、磁盘和开发成本。用户选择两个诱饵入口、后台统计、限量采样，以及逐请求判断而非 IP 封禁。入口中的现有防护和正常凭据、图片例外不能因此放宽。

## Decision

- [360 入口](../../../../extend/360webscan.php)使用[轻量接入](../../../../extend/webscan_honeypot.php)：普通请求只比较实际路由，两个精确诱饵入口及选定的已拒绝请求才加载独立 [Honeypot](../../../../app/service/Honeypot.php)。响应始终在 Composer、会话和业务应用之前结束。`?s=` 语义复用已有请求解析，不另建路由优先级。
- `/api/debug/config` 与 `/api/backup/export` 返回同一批固定虚构数据，后者是纯文本 SQL，GET/HEAD 之外返回 405。现有 WAF 已拒绝的 GET/POST 参数只在前 4 KiB 分类 `UNION … SELECT`；无法识别的情况保留 403。分类不参与放行判断，图片、Cookie 和其他规则不扩大假成功范围。
- 假响应最多 8 KiB，禁止缓存、类型猜测、脚本执行和索引，HEAD 无正文。数据不来自部署配置、用户或上游，所有末尾备注固定为“恭喜，你成功导出了空气”。失败回退终止式 403，记录失败独立忽略。
- [HoneypotLog](../../../../app/service/HoneypotLog.php)只操作三个固定文件：两个交替覆盖的 JSONL 文件各不超过 512 KiB，稳定的采样锁文件固定 64 字节。全站每秒最多 5 条、每条不超过 512 字节，`LOCK_NB` 竞争时立即跳过；同一锁保护采样预算、活动文件编号和写入，不维护按 IP 增长的状态。采样时间在持锁后读取，早于当前窗口的样本直接跳过，避免迟到请求或系统时钟回拨清零限额。文件有效容量保留少量余量，使锁元数据与两份日志的读取总预算不超过 1 MiB。
- 样本只保存时间、固定类型、方法、固定应用/控制器入口标识和 `real_ip()` 解析结果。路径参数、查询串与未知路由文本不保存。正常请求不加载记录组件，也不读写统计文件。没有额外任务、网络请求或业务数据库访问。
- [后台页面](../../../../app/admin/view/system/honeypot.html)在现有 System 控制器及登录/管理员权限检查下提供只读统计，最多显示最近 50 条，无轮询。页面区分诱饵访问和攻击拦截，并说明统计来自保留样本；异常记录作为普通文本转义。
- `HONEYPOT_ENABLED` 读取 PHP 进程环境，默认开启。关闭时诱饵返回 404，现有防护继续拦截，管理页面可读历史。Compose 传入环境变量；镜像更新不会同步宿主 Compose，操作步骤见 [DOCKER.md](../../../../DOCKER.md)。
- [HTTP 夹具](../../../../tests/fixtures/webscan-router.php)在加载防护前绑定临时目录，业务入口另写执行标记，避免将 HTTP 200 当作真实执行证据或把测试样本写入已安装运行目录。

## Alternatives considered

**在业务控制器模拟漏洞、访问真库后替换结果。** 无法保证攻击不触发真实副作用，且每次探测都承担框架和数据库成本。

**独立蜜罐服务、SQL 解释器或延迟响应。** 增加部署、运行资源和维护负担；固定关联数据已满足本轮仿真范围，额外占用工作进程与最低成本目标冲突。

**按来源 IP 封禁或维护长期攻击者会话。** 共享网络和代理出口会连带正常用户，额外状态也可被制造大量来源撑大。

**每次攻击写数据库或持续追加日志。** 攻击流量可以把统计功能变成数据库/磁盘压力源。限量样本与只读页面满足用户明确接受的统计取舍。

**在锁外取时，秒数不同就重新计数。** 迟到的上一秒请求可以回写旧窗口，让当前秒重新取得完整额度；跨秒多进程复现曾在同一秒保存 10 条。窗口只允许前进，时钟回拨期间省略样本，请求防护和蜜罐响应继续执行。

**把所有 403 改为成功或重新实现攻击检测。** 会改变凭据等正常请求语义、掩盖非 SQL 拒绝；现有规则决定拦截，蜜罐只决定有限几类终止响应的呈现。

## Consequences

没有数据库迁移、额外服务或新依赖。真实防护继续依赖权限校验、参数化查询、输出转义等业务边界；固定诱饵不会执行任意 SQL，也不承诺识别所有攻击或承受流量型拒绝服务。统计是有限容量内的采样视图，锁竞争、写入失败和覆盖会减少可见记录，不能当作全量审计计数。

验证包括独立 PHP 8.2.35 环境中的 81 个离线测试与前端交互测试、开启/关闭蜜罐各 78 项原有 HTTP 回归、1.2 万条样本轮换与多进程竞争。第二轮重放了终止式响应、存储故障和管理员权限；通过修改临时源码副本的响应预算触发真实的生成失败分支，确认回退 403 且未进入业务入口。桌面与 390px 浏览器检查确认统计刷新、单面板展示及窄屏表格横向滚动。

2026-11-14 采样窗口修复在本机 PHP 8.3.33 复验：[日志回归](../../../../tests/HoneypotLogTest.php)先红后绿，确认旧样本不改写窗口或计数，下一秒仍可采样。独立多进程跨秒复现修复前后各执行 3 次，同秒记录从 10 条降至 5 条；81 个 PHP 离线测试与前端交互测试全部通过。
