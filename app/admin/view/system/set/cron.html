统一调度覆盖网易云音乐、哔哩哔哩、AnyRouter、AgentRouter 的账号任务，以及 Epic 周免提醒。ANY 和 AG 都有每日定时签到，按账号设置的北京时间执行。

Docker 调度器默认每分钟自动扫描到期任务，通常无需额外监控。ANY / AG 账号须设置挂机时间、开启任务并保持本站会员有效。AG 首次计划当天生效，设定时间已过则立即排队；执行后按次日计划运行。ANY 首次计划通常从次日开始，当天需要执行可在账号页「申请补挂」。网络故障按任务规则自动重试，达到上限后暂停。

如需外部监控，请使用下列地址，并附加 X-Cron-Key 请求头填写运行密钥。复制的地址不包含密钥。

名称地址建议频率操作
统一任务调度（含 ANY / AG 签到） {:get_Domain()}cron/task 每分钟
通知投递与每日总览 {:get_Domain()}cron/notifications 每分钟

在「用户任务列表」查看任务开关与下次执行时间，在「用户账号」进入相应账号查看运行日志。容器部署还需保持 scheduler 服务运行。
